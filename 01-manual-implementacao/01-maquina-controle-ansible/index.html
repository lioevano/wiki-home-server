    Seção 1: Configuração da Máquina de Controle Ansible¶

    A máquina de controle Ansible é o seu "cockpit" para automação. É a partir dela que você executará os playbooks Ansible para provisionar, configurar e gerenciar toda a sua infraestrutura de servidor doméstico.

    Pré-requisitos¶

    • Uma máquina (PC/Notebook) com Linux, macOS ou Windows (usando WSL2).
    • Acesso à Internet para baixar pacotes e coleções Ansible.
    • O repositório homeserver clonado do seu repositório Git, ou com a estrutura de diretórios criada conforme a Seção 0.2: Estrutura do Repositório Git.

    1.1. Instalação do Ambiente de Controle (scripts/bootstrap.sh)¶

    Para simplificar e padronizar a configuração da sua máquina de controle, utilizaremos o script bootstrap.sh fornecido no projeto.

    Conteúdo do Script scripts/bootstrap.sh¶

    O arquivo server/scripts/bootstrap.sh contém: 

    #!/bin/bash
# scripts/bootstrap.sh
# Configura a máquina de controle Ansible (Linux/macOS)

GREEN='\033[0;32m'
YELLOW='\033[0;33m'
RED='\033[0;31m'
NC='\033[0m' # No Color

echo -e "${GREEN}Iniciando a configuração do ambiente de controle Ansible...${NC}"

# 1. Verifica e atualiza o gerenciador de pacotes do sistema
if [[ "$OSTYPE" == "darwin"* ]]; then
    echo -e "${YELLOW}Detectado macOS. Verificando e atualizando Homebrew...${NC}"
    if ! command -v brew &> /dev/null; then
        echo -e "${RED}Homebrew não encontrado. Por favor, instale o Homebrew primeiro.${NC}"
        echo "Visite https://brew.sh/"
        exit 1
    fi
    brew update && brew upgrade
elif [[ "$OSTYPE" == "linux-gnu"* ]]; then
    # Assumindo Debian/Ubuntu. Adapte para outros gerenciadores (yum, dnf) se necessário.
    echo -e "${YELLOW}Detectado Linux (Debian/Ubuntu based). Atualizando apt...${NC}"
    sudo apt update && sudo apt upgrade -y
else
    echo -e "${RED}Sistema operacional não suportado por este script (apenas macOS e Linux baseados em Debian/Ubuntu).${NC}"
    exit 1
fi

# 2. Instala Python 3, Pip e Venv (se não existirem)
echo -e "${YELLOW}Verificando Python 3, Pip e Venv...${NC}"
if ! command -v python3 &> /dev/null || ! python3 -m pip --version &> /dev/null # Venv check removido pois ensurepip instala venv
then
    echo -e "${YELLOW}Python 3 ou Pip não encontrados. Instalando...${NC}"
    if [[ "$OSTYPE" == "darwin"* ]]; then
        brew install python@3.11 # Ou a versão LTS mais recente suportada pelo Ansible
    fi
    if [[ "$OSTYPE" == "linux-gnu"* ]]; then
        sudo apt install -y python3 python3-pip python3-venv # Venv ainda é útil ter explicitamente
    fi
else
    echo -e "${GREEN}Python 3 e Pip já instalados.${NC}"
fi
# Garante que pip e venv estejam associados ao python3 e atualizados
python3 -m ensurepip --upgrade

# 3. Instala Ansible
echo -e "${YELLOW}Verificando e instalando Ansible...${NC}"
if ! command -v ansible &> /dev/null; then
    echo -e "${YELLOW}Ansible não encontrado. Instalando Ansible...${NC}"
    if [[ "$OSTYPE" == "darwin"* ]]; then
        brew install ansible
    fi
    if [[ "$OSTYPE" == "linux-gnu"* ]]; then
        sudo python3 -m pip install ansible # Instalar via pip para versão mais recente
    fi
else
    echo -e "${GREEN}Ansible já instalado.${NC}"
    # Opcional: Atualizar Ansible se já estiver instalado
    # if [[ "$OSTYPE" == "linux-gnu"* ]]; then sudo python3 -m pip install --upgrade ansible; fi
    # if [[ "$OSTYPE" == "darwin"* ]]; then brew upgrade ansible; fi
fi

# 4. Instala coleções Ansible necessárias
echo -e "${YELLOW}Instalando/Atualizando coleções Ansible (ansible/requirements.yml)...${NC}"
ansible-galaxy collection install -r ansible/requirements.yml --force # coleções listadas em ansible/requirements.yml

# 5. Instala SDK Docker para Python (necessário para módulos Docker do Ansible)
echo -e "${YELLOW}Instalando/Atualizando Docker SDK para Python...${NC}"
python3 -m pip install --user --upgrade docker # --user para instalar no diretório do usuário

# 6. Instala Proxmoxer SDK para Python (necessário para módulos Proxmox do Ansible)
echo -e "${YELLOW}Instalando/Atualizando Proxmoxer SDK para Python...${NC}"
python3 -m pip install --user --upgrade proxmoxer

echo -e "\n${GREEN}Configuração do ambiente de controle Ansible concluída!${NC}"
echo -e "${YELLOW}--------------------------------------------------------------------------------${NC}"
echo -e "${YELLOW}Próximos Passos Manuais IMPORTANTES:${NC}"
echo -e "${YELLOW}1. Gere uma chave SSH dedicada para este homelab se ainda não tiver:${NC}"
echo -e "   ${GREEN}ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519_homelab -C \"homelab_ansible_key\"${NC}"
echo -e "${YELLOW}   (Pressione Enter para não definir passphrase para automação total sem ssh-agent, ou defina uma e use ssh-agent).${NC}"
echo -e "${YELLOW}2. A chave pública (~/.ssh/id_ed25519_homelab.pub) precisará ser copiada para o host Proxmox e para as VMs.${NC}"
echo -e "${YELLOW}   O acesso inicial ao Proxmox (como root) para copiar a chave será manual, ANTES de rodar o primeiro playbook nele.${NC}"
echo -e "${YELLOW}--------------------------------------------------------------------------------${NC}"

    Executando o Script bootstrap.sh¶

    1. Torne o script executável: Na pasta server/ do repositório: 
      chmod +x scripts/bootstrap.sh

    2. Execute o script: 

      ./scripts/bootstrap.sh
      O script poderá solicitar sua senha sudo para instalar pacotes no sistema.

    3. Verifique a instalação do Ansible: 

      ansible --version
      Você deverá ver a versão do Ansible, a versão do Python utilizada e os caminhos de configuração.

    Ação Chave SSH (Essencial para Automação)¶

    Ansible se conecta aos servidores (Proxmox host e VMs) via SSH. A autenticação baseada em chaves SSH é o método preferido e mais seguro.

    1. Gere um par de chaves SSH dedicado para este projeto: Se você ainda não tem uma chave SSH que deseja usar especificamente para este homelab, gere uma nova: 

      ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519_homelab -C "homelab_ansible_key"

      • -t ed25519: Especifica o algoritmo de chave (moderno e seguro).
      • -f ~/.ssh/id_ed25519_homelab: Local e nome do arquivo para a chave privada (a pública terá .pub adicionado). Use um nome descritivo.
      • -C "homelab_ansible_key": Um comentário para identificar a chave facilmente.

    2. Sobre a Passphrase da Chave:

      • Sem Passphrase (Mais fácil para automação total): Pressione Enter quando solicitado pela passphrase. A chave privada não será protegida por uma senha adicional.

      Segurança da Chave Privada sem Passphrase

      Se você optar por não usar uma passphrase, qualquer pessoa com acesso ao arquivo da sua chave privada (~/.ssh/id_ed25519_homelab) poderá acessar seus servidores como se fosse você. Proteja este arquivo com permissões restritas (e.g., chmod 600 ~/.ssh/id_ed25519_homelab).

      • Com Passphrase (Mais seguro, requer ssh-agent para conveniência): Digite uma passphrase forte e única. Se você definir uma passphrase, precisará:
        • Digitar a passphrase toda vez que o Ansible usar a chave.
        • Ou usar o ssh-agent para armazenar a chave descriptografada na memória durante sua sessão de login. Para usar ssh-agent: 
          eval "$(ssh-agent -s)"  # Inicia o ssh-agent
ssh-add ~/.ssh/id_ed25519_homelab # Adiciona sua chave ao agent (você digitará a passphrase aqui)

    A chave pública (~/.ssh/id_ed25519_homelab.pub) será o que você copiará para os servidores remotos para permitir o login sem senha via Ansible.

    1.2. Criação e Gerenciamento de Variáveis Sensíveis (Ansible Vault)¶

    Dados sensíveis como senhas, tokens de API e chaves privadas não devem ser armazenados em texto plano no seu repositório Git. O Ansible Vault é a ferramenta integrada do Ansible para criptografar esses dados.

    Caminho recomendado: scripts/gerar_vault.py¶

    São mais de 60 segredos, e a maioria é só um valor aleatório num formato certo (sk- para o LiteLLM, ag- para o hub, digest pbkdf2-sha512 para os clientes OIDC, uma chave RSA para o Authelia, uma chave SSH para o runner do ops). O script gera todos eles a partir do vault.yml.example, na sua máquina, e grava o vault.yml já criptografado: o texto puro só existe em arquivos temporários 0600, apagados no fim. Ele não sobrescreve um vault.yml que já exista.

    cd server
python3 scripts/gerar_vault.py
    1. Ele pergunta a senha do ansible-vault (Enter em branco gera uma). A mesma senha vai para ops_vault_password.
    2. No fim, mostra uma única vez o que você precisa anotar no gerenciador de senhas: a senha do vault (se foi gerada), a do admin do Authelia, as dos admins iniciais do Nextcloud e do Grafana, a do painel do Syncthing, a do usuário Ansible das VMs e a do restic (sem ela, nenhum backup se restaura).
    3. Mostra a chave pública do runner do ops, que vai para o authorized_keys do usuário Ansible das VMs (seção 13).
    4. Lista as chaves que continuam com o texto do modelo, porque vêm de fora: Cloudflare, domínio e e-mail, chaves dos provedores de LLM, bots do Telegram e o id do chat, ProtonVPN, Tailscale, B2, e os tokens criados nas telas depois do primeiro deploy (Grafana, Portainer, Home Assistant, n8n, widgets do painel). Preencha com ansible-vault edit inventories/home/group_vars/all/vault.yml, conforme cada etapa do manual pedir.

    O hash inicial da senha do admin do Authelia sai em pbkdf2-sha512 (o mesmo formato do authelia crypto hash generate pbkdf2), que o Authelia aceita no arquivo de usuários; não precisa do Docker na máquina de controle. Para conferir o resultado antes de usar, rode com --sem-criptografar --saida /tmp/vault.yml (texto puro fora do repositório), olhe e apague. O script só usa a biblioteca padrão do Python e o pacote cryptography, que já vem com o Ansible; os testes (tools/wikisync/tests/test_gerar_vault.py) conferem os formatos e validam os digests com o binário do Authelia.

    Conteúdo de scripts/gerar_vault.py
    scripts/gerar_vault.py
    #!/usr/bin/env python3
# scripts/gerar_vault.py
# Gera o vault.yml a partir do vault.yml.example (página 01): todos os segredos aleatórios (senhas de banco,
# tokens internos, chaves do LiteLLM e do hub, segredos e digests do OIDC, chave RSA do Authelia, chave SSH do
# runner do ops, segredos do Langfuse...) e já criptografa com o ansible-vault. O que vem de fora (Cloudflare,
# Telegram, provedores de LLM, Tailscale, B2, tokens criados nas telas depois do deploy) fica com o texto do
# modelo e aparece na lista do fim: preencha com `ansible-vault edit`.
# Uso (na pasta server/): python3 scripts/gerar_vault.py
# Só a biblioteca padrão e o pacote cryptography (que já vem com o Ansible).
from __future__ import annotations

import base64
import datetime

from cryptography.hazmat.primitives import serialization
from cryptography.hazmat.primitives.asymmetric import ed25519, rsa

SERVER = Path(__file__).resolve().parent.parent
REPO = SERVER.parent
VAULT_DIR = SERVER / "ansible/inventories/home/group_vars/all"
MODELO = VAULT_DIR / "vault.yml.example"
ALFANUM = string.ascii_letters + string.digits


def hexa(n: int) -> str:
    return secrets.token_hex(n)  # n bytes (openssl rand -hex n)


def b64(n: int) -> str:
    return base64.b64encode(secrets.token_bytes(n)).decode()  # openssl rand -base64 n


def senha(n: int = 32) -> str:
    return "".join(secrets.choice(ALFANUM) for _ in range(n))  # só letras e números: serve a qualquer banco


def digest_pbkdf2(segredo: str) -> str:
    """O mesmo formato de `authelia crypto hash generate pbkdf2 --variant sha512` (base64 adaptado, sem '=')."""
    def ab64(b: bytes) -> str:
        return base64.b64encode(b).decode().rstrip("=").replace("+", ".")
    sal = secrets.token_bytes(16)
    return f"$pbkdf2-sha512$310000${ab64(sal)}${ab64(hashlib.pbkdf2_hmac('sha512', segredo.encode(), sal, 310000))}"


def chave_rsa() -> str:
    k = rsa.generate_private_key(public_exponent=65537, key_size=2048)
    return k.private_bytes(serialization.Encoding.PEM, serialization.PrivateFormat.PKCS8,
                           serialization.NoEncryption()).decode()


def chave_ssh() -> tuple[str, str]:
    k = ed25519.Ed25519PrivateKey.generate()
    priv = k.private_bytes(serialization.Encoding.PEM, serialization.PrivateFormat.OpenSSH,
                           serialization.NoEncryption()).decode()
    pub = k.public_key().public_bytes(serialization.Encoding.OpenSSH, serialization.PublicFormat.OpenSSH).decode()
    return priv, pub + " ops-runner"

# Texto de modelo que ainda precisa de você (maiúsculas, domínio e e-mail de exemplo).
PENDENTE = re.compile(r"[A-Z]{3,}_[A-Z_]{3,}|[A-Z]{3,}-[A-Z]{2,}-[A-Z]{3,}|seudominio\.com|example\.com")
LINHA = re.compile(r'^(?P<ind> *)(?P<chave>[A-Za-z_]\w*):(?P<resto>.*)$')


def _casa(caminho: list[str]) -> str | None:
    for padrao in GERADORES:
        partes = padrao.split(".")
        if len(partes) == len(caminho) and all(p in ("*", c) for p, c in zip(partes, caminho)):
            return padrao
    return None


def _valor(texto: str) -> str:
    """Escalar YAML entre aspas duplas (os geradores não produzem aspas nem barras invertidas)."""
    assert '"' not in texto and "\\" not in texto
    return f'"{texto}"'


def gerar(modelo: str, senha_admin: str, senha_vault: str, agora: str) -> tuple[str, dict[str, str], str, list[str]]:
    """Devolve (vault.yml em texto, senhas para anotar, chave pública do runner, chaves que faltam preencher)."""
    linhas = modelo.splitlines()
    saida: list[str] = [
        "# ansible/inventories/home/group_vars/all/vault.yml",
        f"# Gerado por scripts/gerar_vault.py em {agora} a partir do vault.yml.example (página 01).",
        "# Edite SEMPRE com: ansible-vault edit inventories/home/group_vars/all/vault.yml",
    ]
    pilha: list[tuple[int, str]] = []
    anotar: dict[str, str] = {}
    faltam: list[str] = []
    gerados: dict[str, str] = {}
    pub = ""
    i = 0
    # Pula o cabeçalho do modelo ("MODELO versionado...") até a primeira linha em branco.
    while i < len(linhas) and linhas[i].startswith("#"):
        i += 1
    while i < len(linhas):
        linha = linhas[i]
        i += 1
        m = LINHA.match(linha)
        if not m or linha.lstrip().startswith("#"):
            saida.append(linha)
            continue
        ind, chave, resto = len(m["ind"]), m["chave"], m["resto"].strip()
        while pilha and pilha[-1][0] >= ind:
            pilha.pop()
        caminho = [c for _, c in pilha] + [chave]
        pilha.append((ind, chave))
        nome = ".".join(caminho)
        bloco = resto.startswith("|")
        conteudo: list[str] = []
        if bloco:  # o bloco literal vai até a próxima linha menos indentada
            while i < len(linhas) and (not linhas[i].strip() or len(linhas[i]) - len(linhas[i].lstrip()) > ind):
                conteudo.append(linhas[i])
                i += 1
        if not resto or resto.startswith("#"):
            saida.append(linha)  # chave de um mapa (os filhos vêm nas próximas linhas)
            continue
        novo: str | None = None
        if nome == "authelia_admin_password_hash_initial":
            novo = digest_pbkdf2(senha_admin)
        elif nome == "ops_vault_password":
            novo = senha_vault
        elif nome == "ops_ssh_private_key":
            novo, pub = chave_ssh()
        elif caminho[0] == "oidc_clients" and chave == "secret_digest":
            novo = digest_pbkdf2(gerados[".".join(caminho[:-1] + ["secret"])])
        elif (padrao := _casa(caminho)) is not None:
            novo = GERADORES[padrao]()
        if novo is None:
            saida.append(linha)
            saida.extend(conteudo)
            if PENDENTE.search(resto) or any(PENDENTE.search(c) for c in conteudo):
                faltam.append(nome)
            continue
        gerados[nome] = novo
        if nome in PARA_ANOTAR:
            anotar[PARA_ANOTAR[nome]] = novo
        comentario = resto[resto.index(" #"):] if " #" in resto and not bloco else ""
        if bloco or "\n" in novo:
            saida.append(f"{' ' * ind}{chave}: |")
            saida.extend(f"{' ' * (ind + 2)}{l}" for l in novo.strip("\n").splitlines())
        else:
            saida.append(f"{' ' * ind}{chave}: {_valor(novo)}{comentario}")
    return "\n".join(saida) + "\n", anotar, pub, faltam


def _dentro_do_repo(caminho: Path) -> bool:
    try:
        caminho.resolve().relative_to(REPO)
        return True
    except ValueError:
        return False


def _senha_vault(arquivo: str | None) -> tuple[str, bool]:
    if arquivo:
        return Path(arquivo).read_text(encoding="utf-8").strip(), False
    print("Senha do ansible-vault (Enter em branco: gerar uma).")
    s1 = getpass.getpass("Senha do vault: ")
    if not s1:
        return b64(24), True
    if s1 != getpass.getpass("Repita: "):
        sys.exit("As senhas não conferem.")
    if len(s1) < 16:
        sys.exit("Use pelo menos 16 caracteres.")
    return s1, False


def main(argv: list[str] | None = None) -> int:
    ap = argparse.ArgumentParser(description="Gera o vault.yml com todos os segredos aleatórios, já criptografado.")
    ap.add_argument("--saida", default=str(VAULT_DIR / "vault.yml"))
    ap.add_argument("--senha-vault-arquivo", help="arquivo com a senha do ansible-vault (senão, pergunta)")
    ap.add_argument("--admin-authelia-senha-arquivo", help="arquivo com a senha do admin do Authelia (senão, gera)")
    ap.add_argument("--sem-criptografar", action="store_true",
                    help="grava em texto puro (só fora do repositório ou em *.decrypted*; para conferir ou testar)")
    a = ap.parse_args(argv)
    destino = Path(a.saida)
    if destino.exists():
        sys.exit(f"{destino} já existe: não sobrescrevo. Para mudar segredos use ansible-vault edit.")
    if a.sem_criptografar and _dentro_do_repo(destino) and ".decrypted" not in destino.name:
        sys.exit("Em texto puro, só fora do repositório ou num nome *.decrypted* (ignorado pelo git).")
    senha_vault, vault_gerada = _senha_vault(a.senha_vault_arquivo)
    admin = (Path(a.admin_authelia_senha_arquivo).read_text(encoding="utf-8").strip()
             if a.admin_authelia_senha_arquivo else senha(24))
    agora = datetime.datetime.now().strftime("%Y-%m-%d %H:%M")
    texto, anotar, pub, faltam = gerar(MODELO.read_text(encoding="utf-8"), admin, senha_vault, agora)

    if a.sem_criptografar:
        destino.write_text(texto, encoding="utf-8")
        os.chmod(destino, 0o600)
    else:
        # Texto puro só em arquivos temporários 0600 na mesma pasta, apagados mesmo se o ansible-vault falhar.
        with tempfile.TemporaryDirectory(dir=destino.parent, prefix=".gerar-vault-") as tmp:
            claro, chave = Path(tmp) / "vault.decrypted.yml", Path(tmp) / "senha"
            for arq, conteudo in ((claro, texto), (chave, senha_vault + "\n")):
                arq.touch(mode=0o600)
                arq.write_text(conteudo, encoding="utf-8")
            r = subprocess.run(["ansible-vault", "encrypt", "--vault-password-file", str(chave),
                                "--output", str(destino), str(claro)], capture_output=True, text=True)
            if r.returncode != 0:
                sys.exit(f"ansible-vault falhou: {r.stderr.strip()}")

    print(f"\n{destino} gerado" + (" (texto puro)." if a.sem_criptografar else " e criptografado."))
    print("\n=== Anote no seu gerenciador de senhas (não aparecem de novo) ===")
    if vault_gerada:
        print(f"  ansible-vault (e ops_vault_password): {senha_vault}")
    print(f"  admin do Authelia ({'arquivo' if a.admin_authelia_senha_arquivo else 'gerada'}): "
          f"{'(a do arquivo)' if a.admin_authelia_senha_arquivo else admin}")
    for nome, valor in anotar.items():
        print(f"  {nome}: {valor}")
    print("\n=== Chave pública do runner do ops (authorized_keys do usuário Ansible das VMs) ===")
    print(f"  {pub}")
    print("\n=== Ainda com texto de modelo: preencha com ansible-vault edit ===")
    for nome in faltam:
        print(f"  {nome}")
    return 0


if __name__ == "__main__":
    sys.exit(main())

    1.3. Configuração do Inventário Ansible¶

    • Como os hosts são agrupados para aplicar configurações em conjunto.
    • Variáveis específicas de hosts ou grupos.

    Nomes de Hosts vs. IPs de Conexão

    • proxmox_main_host, core-services-vm, ai-desktop-vm são nomes lógicos (apelidos) que você usará nos seus playbooks Ansible para se referir aos hosts.
    • ansible_host especifica o endereço IP real (ou hostname DNS, se você tiver DNS local configurado e funcionando) que o Ansible usará para se conectar ao host.
    • As variáveis *_ip_var são uma convenção para ter os IPs facilmente acessíveis em templates, sem depender da resolução de ansible_host dentro do template.
